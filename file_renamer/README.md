# 文件名自动整理工具

自动识别 PDF / Word 文件内容，按清单顺序重命名。

## 使用方法（给你朋友）

1. 双击 `文件名整理工具.exe`（在 dist 文件夹里）
2. 在上方文本框里填写清单，每行一项，格式：

   ```
   公司资质|资质,营业执照,许可证
   派遣函|派遣函
   说明书|说明,使用说明
   ```

   - `|` 前面是清单名称（重命名后的名字用它）
   - `|` 后面是关键词，逗号分隔，文件内容里出现任意一个就算匹配
   - 不写 `|` 时，名称本身就是要匹配的关键词
   - 第几行就是第几号（例子中"公司资质"就是 1 号）
3. 点【选择文件夹】，选中要整理的文件夹
4. 点【开始匹配】，下方列表显示每个文件的新名字；红色"未匹配"的文件不会被改动
5. 确认没问题后点【确认重命名】

重命名规则：`序号.名称A.pdf`，同一清单项有多个文件时依次用 A、B、C 区分。

规则会自动保存在 exe 旁边的 `匹配规则.txt`，下次打开自动载入，改清单直接改这个文件也行。

## 注意

- 只支持文字版 PDF 和 Word（.docx / .doc）。扫描件图片 PDF 识别不了
- 匹配按从前到后的顺序，文件内容同时含两条规则的关键词时，算先出现的那条
- 重命名前有预览确认，未匹配的文件保持原名
- 对同一文件夹重复运行是安全的，不会产生重复文件

## 打包方法（在你自己的 Windows 电脑上做一次）

1. 安装 Python（python.org 下载，安装时勾选 Add to PATH）
2. 把 `file_renamer.py`、`requirements.txt`、`打包成exe.bat` 放到同一个文件夹
3. 双击 `打包成exe.bat`，完成后 `dist` 文件夹里就是 exe
4. 把 exe 单独发给你朋友即可

不想打包也可以：装好 Python 后双击 `直接运行.bat`（需要连网装一次 pypdf）。
